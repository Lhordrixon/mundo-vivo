# docs/clear-x

Pasta para mantenedores e agentes, fora do caminho do Alan.
Nada aqui é linkado nas aulas nem no COMECE-AQUI.

- `DIAGNOSTICO.md`: fricções medidas da trilha `aprender/` e prioridades.
- `medir.py`: refaz as medições (palavras visíveis por aula).
- `aprendiz-simulado.md`: relatório do aprendiz simulado (um agente que
  sabe só Python e C++ básicos) em cada aula alterada. É filtro de
  defeitos, não prova de que o Alan aprendeu.
- `METRICAS.md`: números semanais gravados pelo `acompanhar.yml`.
