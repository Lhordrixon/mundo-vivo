> [!NOTE]
> 💡 **Ideia** — Pense numa máquina de embaralhar cartas. Se você der a ela o mesmo número de partida, as cartas saem sempre na mesma ordem. Esse número é a **semente**. `random.Random(seed)` é a máquina: um **sorteador** que repete a mesma sequência para a mesma semente. A linha `import random` traz esse sorteador, que já vem com o Python. O mundo do jogo nasce assim.

A partir desta aula, os nomes vêm do Java do jogo, escritos do jeito do Python: `seaLevel` lá vira `sea_level` aqui. Assim você reconhece o código de verdade depois.

## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `sea_level` ↔ `seaLevel`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

- O `classify` do jogo: [WorldGenerator.java, linhas 161–186](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/world/WorldGenerator.java#L161-L186)
- A semente entrando no mundo: [WorldGenerator.java, linhas 57–61](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/world/WorldGenerator.java#L57-L61)

O jogo não sorteia cada tile sozinho: usa um sorteio suave, que forma continentes. A regra da semente é a mesma.

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
if (elevation < seaLevel)          return TileType.SHALLOW_WATER;
if (elevation < seaLevel + 0.015f) return TileType.BEACH;
```

Python:

```python
if elevation < sea_level:
    return "~"
if elevation < sea_level + 0.05:
    return ","
```

No Java, a condição vai entre parênteses e o `if` pode ficar numa linha só. O `f` de `0.015f` diz que é um número quebrado. A praia do jogo é mais fina (0.015) que a da aula (0.05), para aparecer no mapa pequeno. `TileType.BEACH` é um valor de uma lista fixa de tipos de tile.

</details>
