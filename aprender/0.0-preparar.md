## Preparar

Escolha um dos dois. O **ZIP** é um arquivo compactado com o projeto inteiro.

<details open><summary>📱 <b>Celular</b></summary>

1. Na Play Store, instale o **Pydroid 3**.
2. No Chrome, abra `github.com/Lhordrixon/mundo-vivo`.
3. Toque no botão verde **Code** → **Download ZIP**.
   Não achou? Toque em **⋮** e marque **Site para computador**.
4. No app de arquivos, abra **Downloads**, toque em `mundo-vivo-main.zip` → **Extrair**.
5. No Pydroid 3, toque no ícone de pasta. Abra **Download** → `mundo-vivo-main` → `aprender` → `0.0-preparar.py`. Se dentro de `mundo-vivo-main` houver outra pasta `mundo-vivo-main`, abra ela também. Se pedir permissão, toque em **Permitir**.

</details>

<details><summary>💻 <b>PC</b></summary>

1. Em `python.org/downloads`, baixe o Python e instale. No Windows, marque **Add python.exe to PATH** antes de **Install Now**.
2. No GitHub do projeto, clique em **Code** → **Download ZIP** e extraia.
3. Abra o **IDLE** → **File** → **Open...** → `aprender/0.0-preparar.py`.

</details>
