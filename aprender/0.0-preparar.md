> [!WARNING]
> ⚠️ **Armadilha** — Sem aspas, `A` vira um nome que o Python não conhece, e aparece `NameError`. Texto vai sempre entre aspas: `"A"`.

> [!TIP]
> ✅ **Como saber que acertou** — O mapa aparece com a sua letra no meio, e a última linha é **✅ Aula concluída!**.

**Investigar**

1. Dez vezes.
2. Aparece `SyntaxError`. Quer dizer: "escrevi algo que o Python não entende".

```python
minha_letra = "A"
```

```python
linha_do_meio = "~ . " + minha_letra + " . ~"
```
