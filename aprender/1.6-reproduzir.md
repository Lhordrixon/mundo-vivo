## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `can_reproduce` ↔ `canReproduce`, `reproduction_cooldown` ↔ `reproductionCooldown`, `reproduction_hunger_max` ↔ `reproductionHungerMax`, `distance_to` ↔ `distanceTo`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

- O `canReproduce`: [Creature.java, linhas 218–223](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/creature/Creature.java#L218-L223)
- Perto o bastante, então nasce: [Simulation.java, linhas 330–334](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L330-L334)
- O custo para os pais: [Simulation.java, linhas 345–353](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L345-L353)

No jogo, a distância usa x e y (`distanceTo`, [Creature.java, linhas 225–229](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/creature/Creature.java#L225-L229)), e o filho herda a espécie, o reino e os genes dos pais.

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
return isAdult(config)
        && reproductionCooldown <= 0f
        && hunger <= config.reproductionHungerMax
        && health > 0.5f;
```

Python:

```python
return (self.age >= adult_age_seconds
        and self.reproduction_cooldown <= 0
        and self.hunger <= reproduction_hunger_max
        and self.health > 0.5)
```

`&&` é o `and` do Java. `||` é o `or`, e `!` é o `not`. No Java, os campos da própria criatura aparecem sem `self.`.

</details>
