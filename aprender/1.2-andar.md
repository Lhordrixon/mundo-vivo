> [!NOTE]
> 💡 **Ideia** — O jogo anda em **passos** pequenos de tempo. O tempo de um passo se chama `dt` (diferença de tempo). É como um carro: a 60 km/h, em meia hora ele anda 30 km. Aqui, `stride = speed_tiles_per_second * dt` é quanto a criatura anda num passo: 2.2 tiles por segundo, vezes 0.5 segundo, dá 1.1 tile.

## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `move_toward` ↔ `moveToward`, `move_to` ↔ `moveTo`, `speed_tiles_per_second` ↔ `speedTilesPerSecond`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

- `moveToward`: [Simulation.java, linhas 563–581](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L563-L581)
- `moveTo`, que recusa a água: [Simulation.java, linhas 591–602](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L591-L602)
- O teto do passo, `MAX_STEP_SECONDS`: [Simulation.java, linha 45](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L45)

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
int tileX = (int) x;
int tileY = (int) y;

if (!world.inBounds(tileX, tileY) || !world.tileAtUnsafe(tileX, tileY).walkable()) {
    c.targetTile = -1;
    c.targetMateSlot = -1;
    return;
}
c.x = x;
c.y = y;
```

Python:

```python
if mapa[int(y)][int(x)] == "~":
    return
c.x = x
c.y = y
```

`(int) x` no Java é `int(x)` no Python. `!` quer dizer "não", e `||` quer dizer "ou". As chaves `{ }` marcam o bloco, como o recuo no Python. Toda linha termina com `;`. No jogo, a criatura também desiste do alvo (`targetTile = -1`).

</details>
