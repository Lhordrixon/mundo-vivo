> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você faz a criatura andar até um alvo, um pedaço por vez, sem entrar na água.

> [!NOTE]
> 💡 **Ideia** — O jogo anda em **passos** pequenos de tempo. O tempo de um passo se chama `dt` (diferença de tempo). É como um carro: a 60 km/h, em meia hora ele anda 30 km. Aqui, `stride = speedTilesPerSecond * dt` é quanto a criatura anda num passo: 2.2 tiles por segundo, vezes 0.5 segundo, dá 1.1 tile.

**Roseta** — o mesmo trecho nas duas línguas.

Java:

```java
int tileX = (int) x;
int tileY = (int) y;

if (!world.inBounds(tileX, tileY) || !world.tileAtUnsafe(tileX, tileY).walkable()) {
    c.targetTile = -1;
    c.targetMateSlot = -1;
    return;
}
c.x = x;
c.y = y;
```

Python:

```python
if mapa[int(y)][int(x)] == "~":
    return
c.x = x
c.y = y
```

`(int) x` no Java é `int(x)` no Python. `!` quer dizer "não", e `||` quer dizer "ou". As chaves `{ }` marcam o bloco, como o recuo no Python. Toda linha termina com `;`. No jogo, a criatura também desiste do alvo (`targetTile = -1`).
