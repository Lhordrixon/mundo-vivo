<details><summary>🔓 Resposta</summary>

**Investigar**

1. Quando aquele golpe zerou a vida. Bater em quem já morreu devolve `False`, e a morte não é contada duas vezes.
2. `"#" * 5` repete o `#` cinco vezes. Vida 0.5 vira cinco `#`.
3. Fome, terreno e combate tiram vida do mesmo jeito. Um só lugar para conferir e consertar.
4. Quando a `b` saiu da lista, todo mundo andou uma casa para trás, e o `for` pulou a `c`: ela nem levou o golpe.

**Mudar** (qualquer golpe de 0.5 para cima)


**Montar**

```python
def step(creatures, damage):
    for i in range(len(creatures) - 1, -1, -1):
        c = creatures[i]
        if c.apply_damage(damage):
            creatures.pop(i)    # die
```

## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `apply_damage` ↔ `applyDamage`, `step_creature` ↔ `stepCreature`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

- A porta única de dano: [Creature.java, linhas 196–203](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/creature/Creature.java#L196-L203)
- O laço do fim para o começo, com o porquê num comentário: [Simulation.java, linhas 197–202](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L197-L202)
- O `die`: [Simulation.java, linhas 456–460](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L456-L460)

No jogo, morrer também faz o corpo virar comida no tile (`foodMap.deposit`).

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
for (int i = pool.activeCount() - 1; i >= 0; i--) {
    stepCreature(pool.activeAt(i), dt);
}
```

Python:

```python
for i in range(len(creatures) - 1, -1, -1):
    c = creatures[i]
```

O `for` do Java tem três partes, separadas por `;`: o começo (`i = último`), a condição para continuar (`i >= 0`) e o passo (`i--`, que tira 1).

</details>
