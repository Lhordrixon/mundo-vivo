> [!NOTE]
> 💡 **Ideia** — No jogo, morrer é sair da lista de criaturas. Pense numa fila numerada: se a pessoa da posição 1 sai, todo mundo atrás anda um passo, e quem era a 2 vira a 1. Se você ia olhar a posição 2 em seguida, pula essa pessoa. Andando do fim para o começo, quem sai nunca empurra quem você ainda vai olhar.

## 🧩 Montar

O `for c in creatures` do `step` pula criaturas quando alguém sai da lista. Troque por um `for` que vá do fim para o começo, usando índices:

- `range(len(creatures) - 1, -1, -1)` começa no último índice, para antes do -1 e anda de -1 em -1.
- `creatures.pop(i)` tira a criatura da posição `i`.

> [!WARNING]
> ⚠️ **Armadilha** — Tirar itens de uma lista dentro de um `for item in lista` pula itens sem dar erro nenhum. É o pior tipo de bug: o silencioso.

> [!TIP]
> ✅ **Como saber que acertou** — Depois do golpe, sobram só `a` e `d`, e a última linha é **✅ Aula concluída!**.

**Investigar**

1. Quando aquele golpe zerou a vida. Bater em quem já morreu devolve `False`, e a morte não é contada duas vezes.
2. `"#" * 5` repete o `#` cinco vezes. Vida 0.5 vira cinco `#`.
3. Fome, terreno e combate tiram vida do mesmo jeito. Um só lugar para conferir e consertar.

**Mudar** (qualquer golpe de 0.5 para cima)

```python
golpe = 0.5
```

**Montar**

```python
def step(creatures, damage):
    for i in range(len(creatures) - 1, -1, -1):
        c = creatures[i]
        if c.applyDamage(damage):
            creatures.pop(i)    # die
```

No jogo, morrer também faz o corpo virar comida no tile (`foodMap.deposit`).

**Roseta** — o mesmo trecho nas duas línguas.

Java:

```java
for (int i = pool.activeCount() - 1; i >= 0; i--) {
    stepCreature(pool.activeAt(i), dt);
}
```

Python:

```python
for i in range(len(creatures) - 1, -1, -1):
    c = creatures[i]
```

O `for` do Java tem três partes, separadas por `;`: o começo (`i = último`), a condição para continuar (`i >= 0`) e o passo (`i--`, que tira 1).
