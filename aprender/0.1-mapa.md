> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você acha e muda um ponto do mapa com `mapa[linha][coluna]`.

> [!NOTE]
> 💡 **Ideia** — Pense num prédio. Primeiro você escolhe o andar, depois o apartamento. O mapa do jogo é assim: uma lista de linhas (os andares), e cada linha é uma lista de **tiles** (os apartamentos). Tile é cada quadradinho do mapa.

## 🔮 Prever

O arquivo mostra `mapa[2][2]`. Olhe o desenho e conte: o que vai aparecer?

## ▶️ Rodar

📱 Abra `aprender/0.1-mapa.py` no Pydroid e toque em ▶. 💻 Abra no IDLE e aperte **F5**.

## 🔍 Investigar

1. A montanha está na 3ª linha. Por que o código usa `mapa[2]`?
2. O que `mapa[0][0]` mostraria?
3. Quantas listas existem dentro de `mapa`?

## ✏️ Mudar

Coloque uma criatura `"o"` na linha 2, coluna 4. Escreva uma linha só, embaixo do comentário `✏️ MUDAR`.

## 🧩 Montar

Conte quantos `"~"` o mapa tem e guarde o total em `agua`. Use um `for` dentro de outro, como no desenho, e um `if`.

> [!WARNING]
> ⚠️ **Armadilha** — A contagem começa no **zero**: a primeira linha é `mapa[0]`. E a ordem é sempre `[linha][coluna]`: primeiro desce, depois anda para o lado.

> [!TIP]
> ✅ **Como saber que acertou** — O mapa final mostra o `o` na terceira linha, aparece `Água: 28 tiles`, e a última linha é **✅ Aula concluída!**.

<details><summary>🔓 Resposta</summary>

**Investigar**

1. Porque a contagem começa no zero. A 3ª linha é a de número 2.
2. `~`
3. Cinco, uma para cada linha.

**Mudar**

```python
mapa[2][4] = "o"
```

**Montar**

```python
agua = 0
for linha in mapa:
    for tile in linha:
        if tile == "~":
            agua = agua + 1
```

</details>
