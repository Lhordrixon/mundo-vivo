> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você lê uma linha Java do jogo e escreve a mesma coisa em Python.

> [!NOTE]
> 💡 **Ideia** — Java e Python são como dois sotaques da mesma língua. A lógica é igual: `if`, `for`, contas, funções. O Java só pede mais placas no caminho: o **tipo** de cada variável (`int` para número inteiro, `float` para número quebrado), `;` no fim da linha e `{ }` em volta dos blocos.

Só o que o jogo usa, do que mais aparece para o que menos aparece.


> [!WARNING]
> ⚠️ **Armadilha** — Quatro tropeços de quem vem do Python:
> - **Divisão de inteiros:** em Java, `7 / 2` dá `3`. Em Python, `7 / 2` dá `3.5`, e `7 // 2` dá `3`.
> - **Comparar textos:** em Java, use `.equals`. O `==` compara se é o mesmo objeto, não se o texto é igual.
> - **Lista de tamanho fixo:** `new float[size]` não cresce. Não existe `append`.
> - **Tipo obrigatório:** uma variável `float` só guarda números. Não dá para guardar um texto nela depois.
