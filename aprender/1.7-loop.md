## 🧩 Montar

Escreva o `step`. Ele faz duas coisas, nesta ordem:

1. chama `self.regrow(dt)`;
2. chama `self.stepCreature(i, dt)` para cada criatura, do fim da lista para o começo, como na aula 1.5.

Antes de você escrever, o mundo fica parado: as linhas de 5 s a 40 s saem iguais.

> [!WARNING]
> ⚠️ **Armadilha** — Se aparecer `IndexError: list index out of range`, o `for` foi do começo para o fim. A lista encolheu quando alguém morreu, e o índice passou do fim. Leia de novo a aula 1.5.

> [!TIP]
> ✅ **Como saber que acertou** — A população cresce, cai quando a comida acaba e depois se equilibra. A última linha é **✅ Aula concluída!**.

<details><summary>🔓 Resposta</summary>

**Investigar**

1. A fome sobe, quem passou do limite morre, as outras comem, e quem está bem alimentada tem filho.
2. A comida. Quando ela acaba, muitas morrem de fome, e sobram só as que a comida que volta consegue sustentar.
3. Aqui todas dividem a mesma comida. No jogo, quem está num tile vazio precisa andar até outro.

**Mudar**

```python
regrowthPerSecond = 0.5
```

**Montar**

```python
    def step(self, dt):
        self.regrow(dt)
        for i in range(len(self.creatures) - 1, -1, -1):
            self.stepCreature(i, dt)
```

No jogo, o `step` também recalcula o território uma vez por segundo, e cada tile tem a sua comida.

**Roseta** — o mesmo trecho nas duas línguas.

Java:

```java
foodMap.regrow(dt);

for (int i = pool.activeCount() - 1; i >= 0; i--) {
    stepCreature(pool.activeAt(i), dt);
}
```

Python:

```python
self.regrow(dt)
for i in range(len(self.creatures) - 1, -1, -1):
    self.stepCreature(i, dt)
```

No Java, um método chama outro da mesma classe sem escrever `self.` na frente.
