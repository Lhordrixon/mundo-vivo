## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `step_creature` ↔ `stepCreature`, `regrowth_per_second` ↔ `regrowthPerSecond`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

- O `step` do jogo: [Simulation.java, linhas 188–212](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/sim/Simulation.java#L188-L212)
- Quem chama o `step` a cada quadro da tela: [MundoVivoGame.java, linhas 135–136](https://github.com/Lhordrixon/mundo-vivo/blob/348baea45f64869ab0d96f224d2b8c19e5cce7aa/core/src/main/java/com/emannuel/mundovivo/MundoVivoGame.java#L135-L136)

No jogo, o `step` também recalcula o território uma vez por segundo, e cada tile tem a sua comida.

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
foodMap.regrow(dt);

for (int i = pool.activeCount() - 1; i >= 0; i--) {
    stepCreature(pool.activeAt(i), dt);
}
```

Python:

```python
self.regrow(dt)
for i in range(len(self.creatures) - 1, -1, -1):
    self.step_creature(i, dt)
```

No Java, um método chama outro da mesma classe sem escrever `self.` na frente.
