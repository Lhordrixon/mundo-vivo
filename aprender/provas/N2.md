## 1. Divisão (aula 2.1)

Em Java, com `int a = 9;` e `int b = 2;`, quanto vale `a / b`? E em Python, `9 / 2`?

<details><summary>🔓 Resposta</summary>

Java: `4`, porque int / int corta a parte quebrada. Python: `4.5`.

</details>

## 2. Outra cara, mesma ideia (aulas 2.1 e 0.3)

Escreva em Python o mesmo que este Java faz. Quanto dá `metade(7)`?

```java
int metade(int n) {
    return n / 2;
}
```

<details><summary>🔓 Resposta</summary>

```python
def metade(n):
    return n // 2
```

Dá `3`. Com `/`, o Python daria `3.5`: o `//` é o que corta, como o int do Java.

</details>

## 3. A regra muda (aulas 2.1 e 1.3)

Nova regra: a criatura procura comida se `hunger >= 0.42` **ou** se a vida (`health`) for menor que `0.3`. Escreva em Java uma função `procuraComida` que recebe os dois e devolve `true` ou `false`.

<details><summary>🔓 Resposta</summary>

```java
boolean procuraComida(float hunger, float health) {
    return hunger >= 0.42f || health < 0.3f;
}
```

O `or` vira `||`, o número quebrado leva `f`, e cada parâmetro leva o tipo.

</details>

## 4. Do Python para o Java (aula 2.5)

Escreva em Java esta função da aula 2.5:

```python
def tempo_para_atravessar(largura, velocidade):
    return largura / velocidade
```

<details><summary>🔓 Resposta</summary>

```java
float tempoParaAtravessar(float largura, float velocidade) {
    return largura / velocidade;
}
```

`double` no lugar de `float` também vale, e `public` ou `static` na frente são opcionais aqui. `int` está errado: corta a divisão (256 / 6.6 dá uns 38.8).

</details>
