# Correções das aulas

Cada vez que alguém trava numa aula por causa da própria aula, a correção fica registrada aqui, a mais nova no topo. O tutor (`TUTOR.md`) acrescenta uma entrada a cada correção.

Formato de cada entrada:

```
- **AAAA-MM-DD · aula X.Y** — Trava: o que aconteceu. Correção: o que mudou. (#issue)
```
