> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você troca o dicionário por uma **classe** e cria uma criatura nova com uma linha só.

> [!NOTE]
> 💡 **Ideia** — Uma classe é uma forma de biscoito. A forma diz o formato, e cada biscoito sai igual. `Creature` é a forma. `Creature(1, 1)` é um biscoito: um **objeto**. Com dicionários, você escreve as chaves toda vez e pode errar uma letra. Com a classe, a forma escreve por você.

## 🔍 Investigar

Leia a classe com calma:

- `__init__` (dois sublinhados de cada lado) roda quando a criatura nasce.
- `self` quer dizer "eu mesma": a criatura que está sendo usada.
- Uma função dentro da classe se chama **método**. Você usa assim: `c.passar_tempo()`.

## 🧩 Montar

Lá na classe, troque o `pass` do método `comer`. É a mesma regra da aula 0.3: a fome cai 3, mas nunca fica menor que 0. Agora, em vez de `c["hunger"]`, use `self.hunger`.

> [!WARNING]
> ⚠️ **Armadilha** — Dentro da classe, esquecer o `self.` cria uma variável solta, que some no fim do método. Escreva sempre `self.hunger`.

<details><summary>🔓 Resposta</summary>

**Investigar**

1. Fome 3.
2. Sai a chave entre aspas e colchetes, entra um ponto: `c.hunger`.
3. `KeyError: 'hunger'`. O "hungre" errado passou sem aviso e só quebrou agora.

**Mudar**

```python
criaturas.append(Creature(5, 1))
```

**Montar**

```python
    def comer(self):
        self.hunger = self.hunger - 3
        if self.hunger < 0:
            self.hunger = 0
```
