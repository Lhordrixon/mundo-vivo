## 🔗 No jogo de verdade

*Material didático, baseado no [commit](GLOSSARIO.md#commit) `348baea` (versão v0.1.0).*

**Nomes:** `regrowth_per_second` ↔ `regrowthPerSecond`, `delta_seconds` ↔ `deltaSeconds`. Cada linguagem tem sua convenção: em Python, `nomes_com_underline`; em Java, `nomesComMaiuscula`. Classes, como `Creature`, têm o mesmo nome nas duas.

No jogo, a comida volta bem devagar: `0.003` por segundo, e não `0.1`.

<details><summary>🔗 Roseta: o mesmo trecho em Java e em Python (abra depois de terminar)</summary>

Java:

```java
float rate = regrowthPerSecond * deltaSeconds;

for (int i = 0; i < amount.length; i++) {
    float max = capacity[i];
    if (max <= 0f) {
        continue;
    }
    float current = amount[i] + max * rate;
    amount[i] = current > max ? max : current;
}
```

Python:

```python
rate = regrowth_per_second * delta_seconds
for i in range(len(self.amount)):
    novo = self.amount[i] + self.capacity[i] * rate
    self.amount[i] = min(self.capacity[i], novo)
```

`for (int i = 0; i < n; i++)` é o `for i in range(n)` do Java. `a ? b : c` quer dizer "se a, então b, senão c": aqui faz o papel do `min`. `continue` pula para o próximo tile.

</details>
