No jogo, a comida volta bem devagar: `0.003` por segundo, e não `0.1`.

**Roseta** — o mesmo trecho nas duas línguas.

Java:

```java
float rate = regrowthPerSecond * deltaSeconds;

for (int i = 0; i < amount.length; i++) {
    float max = capacity[i];
    if (max <= 0f) {
        continue;
    }
    float current = amount[i] + max * rate;
    amount[i] = current > max ? max : current;
}
```

Python:

```python
rate = regrowthPerSecond * deltaSeconds
for i in range(len(self.amount)):
    novo = self.amount[i] + self.capacity[i] * rate
    self.amount[i] = min(self.capacity[i], novo)
```

`for (int i = 0; i < n; i++)` é o `for i in range(n)` do Java. `a ? b : c` quer dizer "se a, então b, senão c": aqui faz o papel do `min`. `continue` pula para o próximo tile.
