# 0.3 Funções que mudam a criatura

🔁 **Lembra da aula anterior?** Como você muda a fome da criatura `c` para 5?

<details><summary>Ver resposta</summary>

`c["hunger"] = 5`

</details>

> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você escreve uma função que muda a criatura e a usa quantas vezes quiser.

> [!NOTE]
> 💡 **Ideia** — Pense num botão de elevador. Você aperta, e algo sempre acontece do mesmo jeito. Uma **função** é um botão com nome: `def` cria o botão, e escrever o nome com `( )` aperta. O que vai dentro dos parênteses é o **parâmetro**: aqui, a criatura que a função vai mudar. Uma função também pode **devolver** uma resposta com `return`, como a `com_fome`.

## 🔮 Prever

O arquivo chama `desenhar(c)`, depois `andar_direita(c)`, depois `desenhar(c)` de novo. O que muda entre os dois desenhos?

## ▶️ Rodar

📱 Abra `aprender/0.3-funcoes.py` no Pydroid e toque em ▶. 💻 Abra no IDLE e aperte **F5**.

## 🔍 Investigar

1. Quantas vezes a função `desenhar` é usada no arquivo?
2. Dentro de `andar_direita`, o `c` é a mesma criatura de fora?
3. O que `com_fome(c)` devolve quando a fome é 3?
4. Chame `andar_direita(c)` mais uma vez, antes do segundo `desenhar(c)`. O que muda?

## ✏️ Mudar

Na função `passar_tempo`, troque o `pass` pela linha que soma 1 na fome. `pass` quer dizer "não faça nada": é só um lugar guardado.

## 🧩 Montar

Escreva a função `comer`: a fome cai 3, mas nunca fica menor que 0. Use um `if`.

> [!WARNING]
> ⚠️ **Armadilha** — O que fica dentro da função precisa estar recuado com 4 espaços. Sem o recuo, aparece `IndentationError`.

> [!TIP]
> ✅ **Como saber que acertou** — O último desenho mostra `fome: 0`, e a última linha é **✅ Aula concluída!**.

<details><summary>🔓 Resposta</summary>

**Investigar**

1. Três vezes. Sem a função, o desenho estaria escrito três vezes.
2. Sim. A função recebe a mesma criatura e muda ela de verdade.
3. `False`. A fome 3 não é maior ou igual a 5.
4. A criatura aparece um tile mais para a direita no segundo desenho.

**Mudar**

```python
def passar_tempo(c):
    c["hunger"] = c["hunger"] + 1
```

**Montar**

```python
def comer(c):
    c["hunger"] = c["hunger"] - 3
    if c["hunger"] < 0:
        c["hunger"] = 0
```

</details>
