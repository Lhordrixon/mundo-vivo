# 2.5 Mudar um parâmetro e ver no APK

🔁 **Lembra da aula anterior?** O que quer dizer o `f` em `0.45f`?

<details><summary>Ver resposta</summary>

Que o número é um `float`, um número quebrado no Java.

</details>

> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, você prevê em Python o efeito de deixar as criaturas mais rápidas e confere no jogo.

> [!NOTE]
> 💡 **Ideia** — Um **parâmetro** é um botão de ajuste do mundo, como o volume do som. No jogo, eles moram no `CreatureConfig`: velocidade, fome por segundo, idade adulta. Mudar um número muda o mundo inteiro. Antes de mexer, os bons programadores **preveem** o que vai acontecer.

## 🔮 Prever

Com o triplo da velocidade, em quantos segundos uma criatura atravessa os 256 tiles do mundo?

## ▶️ Rodar

1. Rode `aprender/2.5-parametro.py`. Ele compara a velocidade de hoje com a sua e mostra a linha Java nova.
2. No Chrome, abra o [CreatureConfig.java na linha 186](https://github.com/Lhordrixon/mundo-vivo/blob/main/core/src/main/java/com/emannuel/mundovivo/sim/creature/CreatureConfig.java#L186): `public float speedTilesPerSecond = 2.2f;`
3. Como na aula 2.4: lápis → troque `2.2f` pelo seu número com `f` → **Commit changes...** → branch nova `exp/velocidade` → **Propose changes** → **Create draft pull request**.
4. Baixe o APK em **Checks** → **Compilar APK** → **Summary** → **Artifacts** e instale, como na 2.4.
5. Abra o jogo: as criaturas correm.

## 🔍 Investigar

1. No `.py`, o que a função `tilesEm` calcula?
2. Na aba **Checks**, o trabalho **Testes** ficou verde ou vermelho?

## ✏️ Mudar

No `.py`, escolha a velocidade nova: o triplo da de hoje.

## 🧩 Montar

No `.py`, escreva o `tempoParaAtravessar`: os segundos para andar `largura` tiles naquela velocidade.

> [!WARNING]
> ⚠️ **Armadilha** — Os testes medem o mundo. Se o trabalho **Testes** ficar vermelho, toque nele e procure `FAILED` no log: ali está o nome do teste que mediu algo diferente. O APK sai do mesmo jeito, porque é outro trabalho. Mudar um parâmetro de verdade, para ficar no jogo, exige medir várias sementes antes. Isso é coisa do Nível 4. Este PR é experimento: feche sem aceitar.

> [!TIP]
> ✅ **Como saber que acertou** — No celular, as criaturas andam bem mais rápido. O `.py` mostra uns 39 s para atravessar o mundo e termina com **✅ Aula concluída!**.

<details><summary>🔓 Resposta</summary>

**Prever:** uns 39 segundos (256 ÷ 6.6). Hoje são uns 116.

**Investigar**

1. Quantos tiles a criatura anda em tantos segundos: segundos × velocidade.
2. Verde: com 6.6, todos os testes ainda passam. Com outro número, algum pode falhar.

**Mudar**

```python
nova = 6.6
```

**Montar**

```python
def tempoParaAtravessar(largura, velocidade):
    return largura / velocidade
```

</details>
