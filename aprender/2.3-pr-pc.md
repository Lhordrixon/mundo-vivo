## ▶️ Rodar

1. Baixe o GitHub Desktop em `desktop.github.com` e instale.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O Windows avisa que o app é desconhecido.** Clique em **Mais informações** → **Executar assim mesmo**.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

2. Abra e clique em **Sign in to GitHub.com**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O navegador abre e pede autorização.** Clique em **Authorize desktop** e depois em **Abrir GitHub Desktop**.
   - **Não vê o botão.** Menu **File** → **Options** (no Mac, **GitHub Desktop** → **Settings**) → **Accounts** → **Sign in**.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

3. **File** → **Clone repository...** → aba **GitHub.com** → escolha `Lhordrixon/mundo-vivo` → **Clone**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O projeto não aparece na lista.** Aceite o convite: passo 1 da [aula 0.0](0.0-preparar.md). Depois feche e abra o Desktop.
   - **Não acha a aba GitHub.com.** Use a aba **URL** e cole `https://github.com/Lhordrixon/mundo-vivo`.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

4. Clique em **Current branch** → **New branch**. Nome: `docs/melhora-aula`. Clique em **Create branch**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **Não acha Current branch.** É o segundo botão da barra de cima, com o desenho de um galho.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

5. **Repository** → **Show in Explorer** (no Mac, **Show in Finder**). Abra o arquivo da aula num editor de texto e faça a mudança.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O arquivo abre no navegador em vez do editor.** Clique com o botão direito → **Abrir com** → **Bloco de Notas**.
   - **Não acha o arquivo.** As aulas ficam na pasta `aprender`.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

6. Volte ao Desktop. Escreva a mensagem no campo **Summary** e clique em **Commit to docs/melhora-aula**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O botão está cinza.** Falta escrever no **Summary**, ou o arquivo não foi salvo. Salve com **Ctrl+S**.
   - **A lista da esquerda está vazia.** A mudança não foi salva no arquivo. Salve e volte.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

7. Clique em **Publish branch**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O botão diz Push origin.** É o mesmo envio. Clique nele.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>

8. **Branch** → **Create pull request**. O navegador abre: clique em **Create pull request**.

   <details><summary>⚠️ Não funcionou?</summary>

   - **O navegador pede login.** Entre na sua conta e clique de novo em **Create pull request**.
   - Travou mesmo assim? [Abra uma dúvida](https://github.com/Lhordrixon/mundo-vivo/issues/new?template=duvida.yml)

   </details>


<details><summary>Prefere o terminal? Os mesmos passos com git</summary>

```bash
git clone https://github.com/Lhordrixon/mundo-vivo.git
cd mundo-vivo
git switch -c docs/melhora-aula
# mude o arquivo da aula e depois:
git add .
git commit -m "Melhora uma frase da aula 0.0"
git push -u origin docs/melhora-aula
```

Depois, abra o link que o `git push` mostra.

</details>
