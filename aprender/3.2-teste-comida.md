## ▶️ Rodar

1. No GitHub Desktop, crie a branch `teste/foodmap`.
2. Crie `core/src/test/java/com/emannuel/mundovivo/sim/ecology/FoodMapTest.java` copiando o começo do `CreatureTest.java`. Troque o `package` para `com.emannuel.mundovivo.sim.ecology` e o nome da classe para `FoodMapTest`.
