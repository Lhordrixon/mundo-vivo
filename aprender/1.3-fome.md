> [!IMPORTANT]
> 🎯 **Objetivo** — Ao final, a fome da criatura sobe com o tempo, e ela troca de **estado** na hora certa.

> [!NOTE]
> 💡 **Ideia** — Pense no seu humor durante o dia: tranquilo, depois com fome, procurando comida, comendo, satisfeito. Você está sempre em um humor só, e alguma coisa faz você trocar. O jogo chama isso de **máquina de estados**. O estado da criatura é um texto: `"WANDERING"` (vagando), `"SEEKING_FOOD"` (procurando comida), `"EATING"` (comendo), `"SEEKING_MATE"` (procurando parceiro).

## 🔮 Prever

A fome sobe 0.045 por segundo. Acima de 0.42, a criatura procura comida. Em que segundo isso acontece?

Complete o `colorFor`: ele recebe o estado e devolve a cor que o jogo usa. Vagando é `"branco"`, procurando comida é `"amarelo"`, comendo é `"verde"`, procurando parceiro é `"rosa"`.

> [!WARNING]
> ⚠️ **Armadilha** — Números quebrados nunca são exatos no computador: `0.1 + 0.2` dá `0.30000000000000004`. Por isso o código compara com `>=` (maior ou igual), e nunca com `==`.

> [!TIP]
> ✅ **Como saber que acertou** — A linha do tempo mostra a troca em `t=6s` (ou `t=4s`), as cores aparecem no fim de cada linha, e a última linha é **✅ Aula concluída!**.

**Roseta** — o mesmo trecho nas duas línguas.

Java:

```java
switch (state) {
    case SEEKING_FOOD: return COLOR_SEEKING_FOOD;
    case EATING:       return COLOR_EATING;
    case SEEKING_MATE: return COLOR_SEEKING_MATE;
    default:           return COLOR_WANDERING;
}
```

Python:

```python
if state == "SEEKING_FOOD":
    return "amarelo"
if state == "EATING":
    return "verde"
if state == "SEEKING_MATE":
    return "rosa"
return "branco"
```

`switch` escolhe um caminho pelo valor, e `default` é o "senão". No Java, o estado não é um texto: é um **enum**, uma lista fechada de valores possíveis, chamada `CreatureState`.
